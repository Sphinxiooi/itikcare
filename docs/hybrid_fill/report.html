Hybrid Gap Filling

ItikCare egg-yield forecasting. Change record, training parameters and test results.

Status: tested in a dry run only. The ItikCare system and its database are unchanged. Applying this change needs adviser approval.

1. Summary

  • The panel asked for a daily dataset without gaps. We filled three of the four gaps (192 days) with a hybrid method.
  • The hybrid model passes all four forecasting thresholds for daily and tri-day yield.
  • On the full test set it is slightly less accurate than the model trained on real data only.
  • Check the source data before submitting. Some egg counts form straight lines that look estimated, including 42 of the 97 test days. See section 9.
  • The simple rule "same as yesterday" is more accurate than both models.
  • One gap stays empty because the flock was replaced during it.

4. Fill method

Egg yield, flock size, flock age, feed intakeLinear interpolationA straight line from the last usable day before the gap to the first real day after it. Egg yield, flock size and age are rounded to whole numbers.
Temperature, humidityIterative imputer with Extra TreesEstimates each from the trend (days since the first record), the day of the year, and the other weather value. Rounded to one decimal.

Keeping test data out of the fill

Data leakage happens when information from the test days reaches training. Here the test days are the last 15% of each caging period, right next to the gaps.

  1. Split the real data into training and test days first.
  2. Start each straight line from the last training day's values, placed at the end of the period.
  3. Fit the weather imputer without any test-window day.
  4. Keep filled rows out of the test set. Score only on real days.

The line still ends at the first real day after the gap, which is later in time than the test days.

5. Training and parameters

Both models use the project's existing pipeline in forecasting/pipeline.py:

  1. Build lag1 (yesterday's yield) and roll3 (mean of the previous 3 days) inside each continuous segment.
  2. Split each caging period by date: first 85% for training, last 15% for testing.
  3. Estimator: median SimpleImputer, then StandardScaler, then RandomForestRegressor.
  4. Tune with RandomizedSearchCV: 120 candidates, 4 time-ordered folds inside the training data, scored by mean absolute error, seed 42.

Daily and tri-day yield have separate models.

7. Feature importance

The recommendations use the daily model's importances only. There, yesterday's yield and the 3-day average stay on top. Two lower pairs swap order: feed intake moves above flock size, and temperature moves just above humidity. The three prescriptive thresholds have not been re-tested.

The tri-day importances change more (lag1 0.540 to 0.333, flock size 0.072 to 0.154, feed intake 0.037 to 0.135). The recommendations do not read them. Team decision: low priority, no change, since tri-day passes 4/4.

8. Other experiments

What leakage does

When the straight lines started from the test days themselves, error appeared to drop. The drop disappeared once the leak was removed, so those numbers are not valid.

Delta targeting (not adopted)

Delta targeting predicts the change from yesterday and adds yesterday's value back. It lowers error, mostly toward the level of the "same as yesterday" rule, and it changes feature importance heavily. It is recorded here for reference.

9. Limitations

Straight-line egg counts in the source data

In ItikCareDataSet.csv, 88 of 666 days sit in runs where egg yield changes by almost the same amount every day, while temperature and humidity still vary. This pattern usually comes from estimating or interpolating. The file alone cannot show whether these counts were recorded. Compare them with the farm's original records.

Other limitations

  • 192 of 858 days (22.4%) are estimates, not farm records. They must stay labelled and out of the DailyLog table.
  • Filled weather was not compared with recorded weather for those dates.
  • "Same as yesterday" (3 × yesterday for tri-day) passes all thresholds and beats both models.
  • In the existing pipeline, the last two tri-day training rows of each period include egg counts from the first test days (10 rows in total). Removing them and retraining raises tri-day MAE from 43.90 to 49.32 (real data) and from 46.93 to 48.00 (hybrid). Both still pass 4/4. Team decision: accepted, not fixed, disclosed here.
  • Results come from one chronological split and one random seed.
  • Seasonality was not tested.
  • Project spec section 10 says gaps are expected and features must not span them. Spec section 10 and Chapter 3 need updating if this change is adopted.

10. For the manuscript and defense

Suggested Chapter 3 text

Gaps from non-monitoring periods within a flock generation were filled using linear interpolation for egg yield, flock size, flock age and feed intake, and an iterative imputer with an Extra Trees estimator, using trend and day of year, for temperature and humidity. The gap in which the flock was replaced was not filled. Filled values are synthetic estimates, used only for training, and were computed without test-window values. Models were evaluated only on observed data. The hybrid model met all forecasting thresholds but did not improve accuracy on the full test set compared with observed data alone. For the tri-day model, a small number of training targets overlap the first test days; the thresholds were still met when those rows were removed.

Settle the straight-line check in section 9 before using this text.

Likely questions

Is the filled data real?
No. It is labelled synthetic and used only to make the series continuous for training.

Why is one gap still there?
It separates two different flocks. A line between them would describe ducks that did not exist.

Did filling improve the model?
Not on the full test set. It passes the thresholds and is slightly less accurate than real data alone.

Why use a model if yesterday's value is more accurate?
Egg yield changes slowly, so yesterday is a strong predictor. The model also provides the feature importance that the recommendations use. The accuracy limitation remains and should be stated.
